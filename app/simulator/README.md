# 航模飞行姿态模拟器

这是一个Python桌面程序，用于模拟显示航模的飞行姿态以及自平衡动作。

## 功能特点

### 左侧控制面板
- **姿态控制**: 手动调节俯仰角、横滚角、偏航角
- **自平衡模式**: 启用/禁用PID自平衡控制
- **目标姿态设置**: 设置自平衡的目标俯仰角和横滚角
- **飞行数据显示**: 实时显示高度、速度等飞行参数
- **舵面角度显示**: 显示升降舵、副翼、方向舵的当前角度

### 右侧显示区域
- **3D飞行姿态仪**: 显示飞机的三维姿态，包括坐标轴和飞机轮廓
- **纸飞机视图**: 从尾部视角显示纸飞机，包括所有舵面的变化

## 安装和运行

### 1. 安装依赖
```bash
pip install -r requirements.txt
```

### 2. 运行程序
```bash
python flight_simulator.py
```

## 使用说明

### 基本操作
1. **手动控制**: 使用左侧的滑块调节飞机的俯仰角、横滚角、偏航角
2. **自平衡模式**: 勾选"启用自平衡"复选框，程序将使用PID控制自动调节舵面
3. **目标设置**: 在自平衡模式下，可以设置目标俯仰角和横滚角

### 显示说明
- **3D姿态仪**: 
  - 红色箭头: X轴 (机头方向)
  - 绿色箭头: Y轴 (右翼方向)  
  - 蓝色箭头: Z轴 (向上方向)
  - 灰色平面: 水平参考面
  - 黑色轮廓: 飞机轮廓

- **纸飞机视图**:
  - 蓝色机身: 飞机主体
  - 白色机翼: 主翼
  - 灰色尾翼: 水平尾翼
  - 红色升降舵: 控制俯仰
  - 橙色副翼: 控制横滚 (左右相反动作)
  - 绿色方向舵: 控制偏航

### PID参数
程序使用与纸飞机相同的PID参数：
- 俯仰控制: Kp=2.0, Ki=0.1, Kd=0.5
- 横滚控制: Kp=2.0, Ki=0.1, Kd=0.5

## 技术特点

1. **实时动画**: 20FPS的流畅动画显示
2. **PID控制**: 完整的PID自平衡算法，包括死区、积分衰减等
3. **3D可视化**: 使用matplotlib的3D功能显示飞行姿态
4. **舵面模拟**: 详细的舵面角度变化显示
5. **响应模拟**: 模拟飞机对舵面输入的响应

## 系统要求

- Python 3.7+
- Windows/macOS/Linux
- 至少4GB内存
- 支持OpenGL的显卡 (用于3D显示)

## 故障排除

如果遇到显示问题：
1. 确保安装了所有依赖包
2. 检查显卡驱动是否支持OpenGL
3. 尝试降低matplotlib的渲染后端

如果程序运行缓慢：
1. 关闭其他占用资源的程序
2. 降低动画帧率 (修改animate函数中的延迟时间)
