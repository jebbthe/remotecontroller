# 飞行模拟器 v3.1 - 优化版

## 概述

这是一个专为纸飞机自平衡控制系统设计的Python桌面模拟器，基于Tkinter和Matplotlib构建。该版本针对串口数据监控和显示进行了优化，提供了更详细的串口统计信息和动态刷新间隔调整功能。

## 主要功能

### 1. 串口数据监控
- **实时串口连接**: 支持动态串口选择和连接
- **数据统计显示**: 
  - 接收字节数统计
  - 接收行数统计
  - 解析成功次数统计
  - 数据速率显示 (B/s)
- **原始数据显示**: 实时显示最近接收到的原始串口数据
- **时间戳监控**: 显示最后接收数据的时间戳

### 2. 动态刷新间隔
- **自适应刷新**: 根据串口数据更新频率自动调整显示刷新间隔
- **性能优化**: 
  - 高频数据 (< 50ms): 最小20ms刷新间隔
  - 中频数据 (50-100ms): 匹配数据间隔
  - 低频数据 (> 100ms): 最大100ms刷新间隔
- **实时显示**: 当前刷新间隔状态

### 3. 3D姿态显示
- **姿态指示器**: 3D空间中的飞行姿态可视化
- **纸飞机视图**: 尾部视角的纸飞机控制面显示
- **实时更新**: 基于串口数据实时更新显示

### 4. PID数据监控
- **误差显示**: 俯仰和横滚误差
- **积分项**: PID积分项监控
- **输出值**: PID输出值显示
- **舵机位置**: 左右舵机目标位置

## 界面布局

### 左侧控制面板
- **串口配置区域**:
  - 串口选择和波特率设置
  - 连接/断开按钮
  - 状态指示器
- **串口统计区域**:
  - 左侧: 字节数、行数、解析成功数
  - 右侧: 数据速率、刷新间隔、时间戳
  - 原始数据显示框 (支持滚动)
- **姿态数据**: 俯仰、横滚、偏航角度
- **PID数据**: 误差、积分、输出值
- **控制面数据**: 舵面角度和舵机位置
- **数据统计**: 数据计数和更新频率

### 右侧显示区域
- **3D姿态指示器**: 飞行姿态的3D可视化
- **纸飞机视图**: 控制面的2D显示

## 串口数据格式

模拟器解析以下格式的串口数据：

```
[timestamp] Pitch Error: X.XX Roll Error: X.XX Pitch Integral: X.XX Roll Integral: X.XX Pitch Output: X.XX Roll Output: X.XX Right Target: XXX.X Left Target: XXX.X
```

### 数据字段说明
- `timestamp`: 时间戳 (毫秒)
- `Pitch Error`: 俯仰误差
- `Roll Error`: 横滚误差
- `Pitch Integral`: 俯仰积分项
- `Roll Integral`: 横滚积分项
- `Pitch Output`: 俯仰输出
- `Roll Output`: 横滚输出
- `Right Target`: 右舵机目标位置
- `Left Target`: 左舵机目标位置

python flight_simulator_v3.py

## 使用说明

1. **连接串口**:
   - 选择正确的串口和波特率
   - 点击"Connect"按钮连接
   - 观察状态指示器确认连接成功

2. **监控数据**:
   - 串口统计区域显示实时数据接收情况
   - 原始数据显示框显示最近接收的数据
   - 刷新间隔会根据数据频率自动调整

3. **观察显示**:
   - 3D姿态指示器显示飞行姿态
   - 纸飞机视图显示控制面位置
   - 左侧面板显示详细的PID和控制数据

## 故障排除

### 常见问题
1. **串口连接失败**: 检查串口是否被其他程序占用
2. **数据显示异常**: 确认串口数据格式正确
3. **刷新间隔问题**: 检查时间戳数据是否正常

### 调试建议
- 观察原始数据显示框确认数据接收正常
- 检查串口统计信息了解数据流量
- 监控刷新间隔变化确认自适应功能正常
