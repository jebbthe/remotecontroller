# Flight Simulator V3.0 - Performance Optimized

## 概述
这是一个用于远程控制器接收系统的Python桌面模拟器，专门用于可视化飞行姿态和自稳控制动作。V3.0版本针对性能进行了优化，确保实时显示和稳定的数据统计。

## 主要功能

### 1. 实时串口数据可视化
- 支持ESP32接收器的实时串口数据读取
- 适配新的数据格式：`[timestamp] Pitch Error: X.XX Roll Error: X.XX Current Pitch: X.XX Current Roll: X.XX Right Target: XXX.X Left Target: XXX.X`
- 3D姿态指示器和纸飞机可视化

### 2. 智能数据管理
- **队列大小限制**：最大队列大小为10，自动丢弃旧数据
- **最新数据优先**：确保显示最新的串口数据，历史数据可丢弃
- **智能重绘机制**：只在有新数据时重绘图形，减少CPU负载

### 3. 稳定的数据统计
- **累计计数器**：使用累计计数器避免显示回归
- **周期性统计**：分离周期性计数器用于速率计算
- **实时更新**：每秒更新统计信息

### 4. 动态刷新间隔
- 基于时间戳自动调整刷新间隔
- 确保显示与串口数据同步
- 避免不必要的渲染

## 数据格式

### 新的串口输出格式
接收器现在输出以下格式的数据：
```
[12345ms] Pitch Error: 2.50 Roll Error: -1.20 Current Pitch: 1.30 Current Roll: -0.80 Right Target: 95.20 Left Target: 84.80
```

### 字段说明
- `timestamp`: 时间戳（毫秒）
- `Pitch Error`: 俯仰误差
- `Roll Error`: 横滚误差
- `Current Pitch`: 当前俯仰角（传感器数据）
- `Current Roll`: 当前横滚角（传感器数据）
- `Right Target`: 右舵机目标位置
- `Left Target`: 左舵机目标位置

## 界面布局

### 左侧控制面板
1. **Attitude Data**: 显示当前俯仰、横滚、偏航角
2. **Control Errors**: 显示控制误差（俯仰误差、横滚误差）
3. **Control Surfaces**: 显示舵面角度和舵机位置
4. **Data Statistics**: 显示数据统计信息

### 右侧可视化区域
1. **3D姿态指示器**: 实时显示飞行姿态
2. **纸飞机视图**: 从尾部向前看的视角，显示左右大翼（一字型）和控制面动作

### 串口配置面板
1. **串口设置**: 端口选择、波特率配置
2. **连接控制**: 连接/断开按钮
3. **数据统计**: 字节数、行数、解析成功率、数据速率
4. **原始数据显示**: 最近接收的原始串口数据

## 性能优化

### 1. 数据队列管理
- 限制队列大小为10个数据点
- 自动丢弃最旧的数据
- 确保显示最新的串口数据

### 2. 智能重绘机制
- 只在有新数据时标记需要重绘
- 动画循环中只在需要时重绘图形
- 减少不必要的渲染操作

### 3. 稳定的统计显示
- 使用累计计数器避免显示回归
- 分离周期性计数器用于速率计算
- 每秒更新统计信息，避免频繁更新

### 4. 动态刷新间隔
- 基于时间戳计算数据间隔
- 自动调整刷新频率
- 确保显示与数据同步

## 安装和运行

### 依赖包
```bash
pip install tkinter matplotlib pyserial numpy
```

### 运行模拟器
```bash
python flight_simulator_v3.py
```

## 使用说明

1. **连接串口**：
   - 选择正确的串口和波特率（默认9600）
   - 点击"Connect"按钮连接

2. **查看数据**：
   - 左侧面板显示实时数据
   - 右侧显示3D姿态和纸飞机视图
   - 底部显示串口统计和原始数据

3. **性能监控**：
   - 观察数据速率和刷新间隔
   - 检查解析成功率
   - 监控CPU使用情况
